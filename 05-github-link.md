# Assignment 5 – GitHub repository link

## Push steps

1. On github.com click **New repository** → name it `Web-Foundation-Assignments` → leave it empty (no README) → **Create**.
2. In your local project folder:
   ```bash
   git remote add origin https://github.com/Gautam-Prabhat/Web-Foundation-Assignments.git
   git branch -M main
   git push -u origin main
   ```
3. Refresh the GitHub page and confirm all files and commits appear.

## Optional: host it for free

_Settings → Pages → Branch: main / root → Save._ Your pages will be live at  
`https://Gautam-Prabhat.github.io//Web-Foundation-Assignments`.
